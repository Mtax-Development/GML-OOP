A project file exemplifying **GML-OOP** shape rendering and input interaction.

Contains setup for rendering several shapes with multi-color filling and outline, each separately changing the color of their outline over time, in response to system cursor being placed over them or leaving their total area.

<a href="https://github.com/Mtax-Development/GML-OOP/tree/Examples/Precise%20Shape%20Collisions"><img src="https://raw.githubusercontent.com/Mtax-Development/GML-OOP/refs/heads/Examples/Precise%20Shape%20Collisions/Precise%20Shape%20Collisions.gif" alt="Precise collision example of a cursor collision with a RoundRectangle shape"></a>

Serves as a minimal example of working with following libraries, requiring them to be imported into the same project: [GML-OOP](https://github.com/Mtax-Development/GML-OOP), [GML Instantiable Constructors](https://github.com/Mtax-Development/GML-Instantiable-Constructors) and [GML Development Toolbox](https://github.com/Mtax-Development/GML-Development-Toolbox).
